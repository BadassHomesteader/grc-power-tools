Questions

Quick answers.

Is this available for Windows or Linux?

Not yet — today Power Tools is native macOS on Apple Silicon. We're working on Windows and Linux versions; watch Releases to be first in line.

What does it cost?

Nothing. Free and open source (MIT) — no account, no subscription, no telemetry.

Does my voice or screen leave my Mac?

No. Dictation, OCR and the pad suggestions run on-device. Only the opt-in AI features (AI chat, cloud cleanup, smart paste) call out — with your own API key, and only when you use them.

What do I need to run it?

macOS 26+ on Apple Silicon. Grant Microphone and Accessibility when prompted — the built-in Permission Doctor checks the rest.
